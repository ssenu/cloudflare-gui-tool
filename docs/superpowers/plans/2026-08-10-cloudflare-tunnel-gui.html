2026-08-10 · 총 14개 태스크 · TDD (테스트 먼저 → 구현 → 커밋) · 상세 코드 리스팅은 동명 .md 파일 참조

개요

목표: cloudflared 터널 생성/목록/on-off/웹서버 실행/SSH 원격 제어를 GUI로 수행하는 PyQt6 데스크톱 앱.

아키텍처: core(비-Qt 순수 파이썬)와 ui(PyQt6)를 분리. UI는 QTimer 폴링으로 core의 상태/로그를 읽음 (크로스스레드 시그널 문제 회피). 로컬 = subprocess, 원격 = paramiko SSH, 동일 CommandRunner 인터페이스.

기술: Python 3.11+ · PyQt6 · PyYAML · paramiko · pytest

전역 제약

  • 모든 cloudflared 명령은 CommandRunner 경유 (UI에서 subprocess 직접 호출 금지)
  • core 모듈은 PyQt6를 import하지 않음
  • 설정: %APPDATA%/CloudflareTunnelGUI/settings.json / 터널 config: ~/.cloudflared/config-<이름>.yml
  • SSH 비밀번호 디스크 저장 금지 · UI 한국어 · 커스텀 QSS 다크 테마
  • 단순화 2건: 루트 도메인은 최초 수동 입력 후 기억 / 원격 상태는 SSH 채널 생존으로 판정
